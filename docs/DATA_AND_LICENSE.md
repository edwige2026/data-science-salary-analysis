# Data source and licensing notes

## Data source

Badole, S. **Latest Data Science Job Salaries 2020–2024**. Kaggle:
<https://www.kaggle.com/datasets/saurabhbadole/latest-data-science-job-salaries-2024>

The dataset supplied with the original assignment contained 14,838 records and 11 columns. The CSV is intentionally **not committed** to this repository. Download it from the source page and place it at `data/raw/DataScience_salaries_2024.csv` before running the scripts.

## Before redistributing data

Kaggle datasets can use different license terms. Check the current license shown on the dataset page and follow its attribution or other conditions before committing the CSV to a public repository or republishing it elsewhere. The license of this project’s code does not change the license of third-party data.

## Project code

The MIT license in the repository applies to the project code and original project documentation only. It does not grant rights to third-party datasets or sources cited in the project.
